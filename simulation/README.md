# Cyclic pursuit simulation

- [`cyclic.ipynb`](cyclic.ipynb): main simulation notebook.
- [`tuning_params.ipynb`](tuning_params.ipynb): example controller parameter settings.
- [Moving-centroid GIF](../media/moving_centroid.gif): visual demonstration.

From the repository root, install `jupyterlab numpy scipy matplotlib pandas tqdm pillow` and run `python -m jupyterlab`.

These are the notebook files from the prior `main` branch, reorganized without editing their internals. See the [project README](../README.md) for assumptions and caveats.
